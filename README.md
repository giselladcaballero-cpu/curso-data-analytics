## Proyecto integrador: RetailPro

Distribuidora de tecnología con datos de ventas, clientes, productos y territorios. El objetivo es construir el sistema de análisis completo, desde la base de datos hasta el dashboard ejecutivo.

**Pregunta diagnóstica:** ¿Por qué cayeron las ventas de la región Norte en el último trimestre, qué categorías lo explican y si se perdieron clientes o los clientes compran menos?

## Herramientas

- SQL Server + SQL Server Management Studio (SSMS)
- Power BI
